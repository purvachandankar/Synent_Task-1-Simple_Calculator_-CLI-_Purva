# Synent_Task-1-Simple_Calculator_-CLI-_Purva

## 📌 Objective

The objective of this project is to develop a simple command-line calculator using Python that performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

## 🛠️ Tools & Technologies Used

- Python
- Command Line Interface (CLI)
- Python OOP (Class and Objects)

## ⚙️ Steps Performed

1. Took two numbers as input from the user.
2. Created a `Calculator` class to perform arithmetic operations.
3. Implemented methods for:
   - Addition
   - Subtraction
   - Multiplication
   - Division
4. Created an object of the `Calculator` class.
5. Displayed a menu to allow the user to select an operation.
6. Used a `while` loop to continuously perform calculations until the user chooses Exit.
7. Added validation to prevent **division by zero**.
8. Added handling for invalid menu choices.

## ✨ Features

- Addition of two numbers
- Subtraction of two numbers
- Multiplication of two numbers
- Division of two numbers
- Division-by-zero handling
- Interactive CLI menu
- Exit option

## 📊 Outcome

Successfully developed a functional **command-line calculator** using Python. The project provided practical experience with **classes, objects, methods, loops, conditional statements, user input, and basic error handling**.
